# 文件夹自动清理 (Folder Auto Cleaner) — Magisk / KernelSU 模块 v1.9.8

监听指定文件夹，当总大小超过阈值时，自动按「文件修改时间从旧到新」删除最旧的普通文件，直到目录大小回落到**保留值**以下。内置中文 Web UI（默认端口 8899），支持多套配置方案切换、实时占用、目录分类统计、清理记录、运行日志、主题切换。

## ✨ 功能

### 核心清理
- **守护进程**：开机自启，2 秒短循环轮询，配置变更 2 秒内热重载。
- **保留值 (Keep Size)**：阈值触发后，不是删到阈值以下就停，而是删到你设定的保留大小。例如阈值 50GB、保留 30GB，则超过 50GB 时删到 30GB 左右停止。
- **按 mtime 从旧到新删除**：保留最新的文件，适合录播、下载目录等「越新越重要」场景。
- **跳过隐藏文件**（.开头）和 .nomedia 文件。
- **阈值为 0 时不启用清理**：保留值和检查间隔自动禁用。

### 多配置管理
- **多套 Profile**：例如「录播」「下载」「测试」可以分别监听不同目录，随时切换。
- **新建 / 重命名 / 删除**：不能删除正在使用的配置；删除时校验。
- **导出 / 导入 JSON**：方便备份和跨设备迁移。
- **端口全局**：不随 Profile 变化，通过弹窗修改。

### 系统路径保护
自动拒绝以下路径（受保护时变灰、提示）：
`/`, `/system/*`, `/data/adb/*`, `/sdcard/Android/*`, `/root/*`, `/dev/*`, `/proc/*`, `/sys/*`, `/vendor/*`, `/product/*`

### 校验规则
- 保留值必须小于阈值
- 阈值不能大于设备总容量
- 阈值 − 保留值不能大于设备剩余空间
- 启用清理时路径必须存在且非空

### Web UI
- **亮色 / 深色主题切换**（localStorage 记忆）
- **PC 三栏布局**：左 运行日志（深色面板）· 中 状态+目录内容 · 右 清理记录
- **手机单列布局**：目录内容 → 清理记录 → 运行日志
- **磁盘空间告警**：剩余 < 5% 或 < 2GB 顶部红色提示条
- **右上角悬浮 Toast**：成功 / 失败 / 提示，不再打扰用户
- **配置弹窗**：路径确认、阈值/保留实时预览、校验提示
- **清理记录卡片**：按日期分组（今天/昨天/更早），手风琴展开（一次只展开一个），文件详情点击展开（不弹窗）
- **目录内容统计**：按扩展名分类（视频/图片/音频/文档/压缩包/字幕/安装包/其他），显示数量与占用大小；后端带文件数缓存
- **运行日志**：展开状态记忆，支持复制 / 导出
- **测试工具**：一键生成 3 个小文件 / 混合文件 / 5×50MB / 2GB 大文件 / 清空测试目录

## 📦 安装

1. 把 `FolderCleaner-vX.X.X.zip` 传到手机。
2. 在 Magisk / KernelSU / ResuKisu 里「从本地安装」。
3. 重启手机。
4. 浏览器打开 `http://<手机IP>:8899`。

## 💾 数据文件（/data/adb/folder-cleaner/）

| 文件 | 用途 |
|---|---|
| `profiles.conf` | 多套配置，格式 `name\|watch_dir\|threshold_gb\|interval_sec\|keep_gb` |
| `config.conf` | 当前激活配置名 + 端口 |
| `cleaner.log` | 运行日志 |
| `cleanup.log` | 清理记录（JSON 格式，含删除文件列表） |
| `daemon.pid` | 守护进程 PID |
| `force_clean` | 手动清理触发标记（touch 即触发） |
| `.stats_*` | 目录统计缓存（按路径 md5 命名） |

## 🔌 API 接口

| action | 说明 |
|---|---|
| `status` | 当前配置 + 占用 + 磁盘信息 + 所有 Profile |
| `save` | 保存当前 Profile（含路径校验） |
| `switch` | 切换激活 Profile |
| `delete` / `rename` | 删除 / 重命名配置 |
| `clean` | 手动触发一次清理 |
| `test` | 测试工具：small / mixed / mid5 / big / clear |
| `log` | 运行日志（最近 40 行） |
| `cleanup` | 清理记录（最近 200 条 JSON） |
| `browse?path=` | 浏览子目录（文件选择器用） |
| `stats` | 目录分类统计（带缓存） |

## ⚠️ 安全提示

- Web UI 监听 `0.0.0.0`，同一局域网内任何人都能打开。
- 建议不要把监听目录指向系统关键路径（已做白名单保护，但仍需小心）。
- 测试工具固定操作 `/storage/emulated/0/FolderCleanerTest`，不影响真实目录。

## ❓ 常见问题

- **Web 打不开？** 检查端口是否被占用；`cat /data/adb/folder-cleaner/cleaner.log` 看错误。
- **清理不触发？** 阈值是 0 表示不启用；检查间隔太短可能等不及。
- **统计不准？** 文件数没变时用缓存；手动生成/删除文件后等一个轮询周期（默认 10s）。
